## 3. Top 3 Failed Queries

The following queries received thumbs-down feedback, ranked from most recent to oldest:

### Failed Query #1 — Tool Error
- **Date:** 2026-04-11
- **Query:** `Send a reminder to EMP-002 about the IT Equipment Setup task.`
- **Agent Response:** `I tried to send a reminder about the IT Equipment Setup task but encountered an error with the task name lookup.`
- **User Comment:** "The agent tried to call the tool with wrong task name format."
- **Root Cause:** The `send_reminder_email` tool was called with an imprecise task name that didn't match the exact database record. The agent failed to first call `get_task_status` to verify the exact task name before sending the reminder.

### Failed Query #2 — Hallucination
- **Date:** 2026-04-08
- **Query:** `What is the company policy on remote work during onboarding?`
- **Agent Response:** `The company allows remote work during the first week of onboarding for employees in the engineering department. Other departments may have different policies...`
- **User Comment:** "This information isn't in our policies. The agent made it up."
- **Root Cause:** The policy knowledge base does not contain a remote work policy. Instead of responding "I don't have that information," the agent hallucinated a plausible-sounding policy.

### Failed Query #3 — Incomplete Answer
- **Date:** 2026-04-04
- **Query:** `Check the onboarding status for EMP-001 and tell me what to do about overdue tasks.`
- **Agent Response:** `Here is the onboarding status for EMP-001: 5/15 tasks completed (33%). There are 3 overdue tasks: Benefits Enrollment, Signed Offer Letter...`
- **User Comment:** "Agent listed the overdue tasks but didn't actually recommend what to do about them."
- **Root Cause:** The agent only partially answered the query. It retrieved the status but ignored the second part of the request — recommending action on overdue tasks (e.g., send reminders, escalate).

## 5. Recommendations

Based on the three failure categories identified:

### 5.1 Fix Hallucination (Query #2)
Add an explicit grounding rule to the system prompt:
> "If you cannot find the answer in the retrieved documents, respond with: 'I could not find this information in the company knowledge base. Please contact HR directly.' Do NOT guess or infer policies that are not explicitly documented."

### 5.2 Fix Tool Error (Query #1)
Update the system prompt with a two-step verification rule:
> "Before calling `send_reminder_email`, always call `get_task_status` first to retrieve the exact task name as stored in the database. Use only exact task names from tool output — never rephrase or guess task names."

### 5.3 Fix Incomplete Answer (Query #3)
Add a completeness instruction to the system prompt:
> "When a user's query contains multiple requests (e.g., 'check status AND tell me what to do'), you must address every part of the request. Do not stop after the first part."
