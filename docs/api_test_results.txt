TEST 5: POST /api/stream (SSE streaming)
--------------------------------------------------------------
$ curl -s -N -X POST http://localhost:5000/api/stream \
  -H "Content-Type: application/json" \
  -d '{"message": "Get employee info for EMP-001", "mode": "single"}'

data: {"type": "tool_call", "node": "agent", "tool": "get_employee_info", "args": {"employee_id": "EMP-001"}}

data: {"type": "tool_result", "node": "tools", "tool": "get_employee_info", "content": "Employee Record:\n  ID: EMP-001\n  Name: Alice Johnson\n  ..."}

data: {"type": "agent_response", "node": "agent", "content": "Here is the employee information for EMP-001:\n\n- **Name:** Alice Johnson\n- **Role:** Software Engineer\n- **Department:** Engineering\n..."}

data: {"type": "done"}

Status: 200 OK (text/event-stream)
